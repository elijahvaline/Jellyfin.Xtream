Dynamic channels

Each rule adds every Live TV channel whose name contains the keyword (case-insensitive) in the selected categories, or in all categories if none are selected. Rules are checked again on every guide refresh, and channels that no longer match are removed. When "Favorite" is on, matched channels are marked as a favorite for every user once they appear. You can still remove the favorite yourself after that.
